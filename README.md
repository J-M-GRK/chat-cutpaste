# Chat Cut & Paste (SillyTavern 확장)

채팅 화면에서 메시지를 직접 골라 복사/잘라내고, 다른 채팅방(또는 같은 방)의
원하는 위치에 붙여넣는 확장입니다.

## 설치
1. https://github.com/J-M-GRK/chat-cutpaste 해당 주소를 실리태번 확장 설치에 붙여넣습니다.

## 사용법
1. **선택 시작**: 메시지 우측 `...` 버튼 안의 ✂ 아이콘, 또는 마법봉(확장) 메뉴의 "채팅 선택"
2. **고르기**: 메시지를 누르면 선택/해제, Shift+클릭은 범위 선택. 떨어져 있는 메시지도 가능
3. **복사 / 잘라내기** 버튼 → 상단 바에 클립보드 상태가 표시됨
4. **붙여넣을 채팅방으로 이동** (평소처럼 채팅 전환, 캐릭터가 달라도 됨)
5. 붙여넣을 위치의 메시지 아래 **"여기에 붙여넣기"** 바를 누르거나, 상단 바의 "맨 위/맨 아래" 사용

## 동작 방식 / 안전장치
- 잘라내기는 **붙여넣는 순간** 원본에서 삭제됩니다. 잘라낸 메시지는 흐리게 표시됩니다.
- 붙여넣기 전에 원본 메시지가 그대로인지 검증하고, 달라졌으면 아무것도 건드리지 않고 중단합니다.
- 다른 방에서 잘라낸 경우: 대상 저장 성공 → 원본 삭제 순서라서 실패해도 메시지가 사라지지 않습니다.
- 복사는 한 번 하면 여러 곳에 반복해서 붙여넣을 수 있습니다.
- 클립보드는 새로고침해도 (같은 탭에서는) 유지됩니다. Esc로 선택 모드 종료.

## 제한
- 그룹 채팅에서 잘라낸 메시지는 같은 채팅방 안에서만 붙여넣을 수 있습니다 (다른 방은 "복사" 사용).
- 잘라내기 후 원본 메시지를 수정하면 검증에 실패해서 중단됩니다.
